# WPS 表格的状态与完成证据

适用范围：Android 包 `cn.wps.moffice_eng`。包名来自已核对的本地宿主文档打开范围；菜单和编辑行为没有按所有 WPS 版本核验。这份资料是通用状态参考，不能作为已成功执行的路线。当前截图、可用节点和文件读回结果决定操作与结论。

按用户目标分阶段检查：可见新建入口 → 正确类型的空白工作簿 → 指定单元格及编辑状态 → 文本已经提交 → 文件命名与保存 → 内容读回。不要把空白表格已打开当作写入成功。

当前在首页/文件列表时，从当前画面寻找新建及表格类型入口；辨认模板页和空白工作簿。打开后应能解释列标、行号、单元格选区或当前工作表。不假设某个角落必定有加号，不凭其他版本记忆点击。

单元格选中与文字编辑是两种状态。先核对目标地址，再确认光标、当前编辑区域或公式栏；网格高亮不足以证明能直接输入。输入后检查实际单元格内容并提交，之后才能切到下一格。键盘变化后重新定位。

- 需要选择单元格、输入中文、确认编辑与提交：读取 `references/cells-and-input.md`。
- 需要命名、保存、确认文件和读回内容：读取 `references/save-and-verify.md`。
- 来源、C6 观察限制和未知版本行为：读取 `references/sources.md`。

遇到登录、会员、云端选择或权限对话框，应依据用户目标与宿主授权处理，不把订阅流程当作新建表格的必经步骤。已有文档覆盖与用户数据修改须由原任务覆盖；资料不扩大授权范围。
