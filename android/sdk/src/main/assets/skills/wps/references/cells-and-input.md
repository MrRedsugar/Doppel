# 从单元格选择到已提交文字

这是 WPS 表格的状态检查方法。没有已核验的固定按钮序列、双击时机或坐标；编辑入口应由当前客户端显示决定。

先识别当前工作表和目标单元格。列标、行号、名称框、公式/编辑栏和选区都可作为候选证据，实际可见哪些就用哪些。屏幕上有表格网格不代表当前是 A1，也不代表整张表格作为节点可编辑。

选中单元格后检查是否出现编辑光标、对应的编辑栏或可编辑节点。如果只有边框高亮，应继续辨认可见编辑入口；不能把文字直接提交给未知焦点。若需要进一步点按，由当前画面支持的候选决定，并观察实际反馈，不把“两次点击”写成跨版本固定要求。

输入中文时，确认完整内容进入预期字段。文字仍在输入法候选栏、公式栏但未提交、或旁边另一单元格，都不满足目标。提交后读回该格，检查中文、数字、日期或换行是否按用户要求保留；可能被格式化的内容需要读回实际值或显示值并说明区别。

多个单元格输入应保持“地址 → 编辑 → 输入 → 提交 → 读回”的连续证据。已确认稳定的同一编辑状态可使用宿主允许的短动作段；单元格编辑模式、键盘、对话框或滚动改变时需新观察。没有验证制表符/换行粘贴到多格的行为时，不将其当作默认批量导入方法。

一次输入未生效时，先检查当前焦点、文本是否仍处于候选/未提交状态、动作回执和目标地址。没有输入动作或焦点证据时不能归因为中文输入法；不要在不确定状态重复输入导致内容叠加。
