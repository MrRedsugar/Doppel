# 文件命名、保存与读回

开始保存前先核对需要写入的内容已提交。依据当前标题、文件菜单、保存图标或应用提示识别保存入口；具体按钮名称和顺序随版本变化。没有观察到的“菜单 → 另存为”层级不能作为事实路线。

出现命名弹窗时核对字段标签、当前文件名和扩展名。按用户指定名称填写；不要把单元格编辑框误当文件名输入。出现位置选择时识别本地/云端位置和实际可用项。账户登录或会员弹窗不证明保存必须付费，依据当前可见选项和任务范围重新判断。

保存后确认已离开命名弹窗、标题/文件列表显示目标名称，并检查可见保存状态。提示消失、按钮回执或标题变化都只能形成部分证据。仍有未保存提示、上传进度或错误时，应保留为未完成。

若宿主已提供目标文件读取能力，使用实际保存的文件或受控文件引用进行独立读回，核对工作表、单元格和文本值。检查文件名/路径与本次输出一致，避免读取同名旧文件。不具备文件访问能力时，不编造内部路径、文件已落盘结论或读回成功；如实说明仅能验证画面上的结果。

不能用新建空白工作簿、看见键盘、启动保存或收到输入回执代替“中文内容按要求写入且命名保存”。业务完成与工具成功分别判定。
