版本 2026.09.09.1；2026-09-09 编写。`cn.wps.moffice_eng` 来自 Doppel 既有 scoped open_document 包范围及本地 WPS 验收记录。此包名仅确定应用身份，不确定 UI 版本。

本地 C6 任务尝试新建、中文写入和保存表格，实际只到空白工作簿，未完成写入保存。后续在同一历史画面上的只读模型探针提出直接输入，但没有派发输入，也没有验证焦点有效，因此不能引用为已成功编辑的证据。

本资料由 Doppel 独立编写，使用通用表格编辑状态与保存验证方法；没有引用未实际读取的 WPS 官方教程，也没有复制第三方攻略。本轮没有新检索 WPS 在线教程或验证指定版本的菜单层级、双击入口、公式栏可编辑行为和保存位置。未验证的具体行为必须由当前画面和实际回执确认。

不含真实账户、文档内容、设备坐标或私有文件路径。用户登录态、会员范围、云端保存权限、客户端版本和语言均可能改变可见流程；不能将这份资料推广为所有 WPS 安装的固定操作脚本。
