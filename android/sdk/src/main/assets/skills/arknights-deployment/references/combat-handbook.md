# 战斗操作手册

按当前画面进入对应步骤。正在选择朝向就完成朝向，已部署完就继续战斗，不从第一步重来。B无前文，每次把所指对象重新说清。

## 1. 进入战斗，先把游戏暂停
1. 从关卡详情点“开始行动”；出现编队页后确认当前队伍，再点编队页的“开始行动”。教学若提示“本次行动配置不可更改”，使用给定队伍。
2. 等加载图切到可见战场、右上倍速与暂停控件。点右上两条竖线，看到中央PAUSE/暂停中才开始长时间规划。1X/2X是倍速，旁边三角形是恢复；不要把它们混为同一按钮，也不要猜左上有暂停。
3. 有教学对白时先读这条提示，按高亮对象或“点击继续”推进。需关闭剧情时点可见“跳过”，再在“是否跳过剧情？”中点对勾。对白消失后立即重新找暂停控件；跳过对白不代表游戏已经暂停。
4. 点选干员会展开面板，不能因此当作暂停。切图、关闭弹窗、重开关卡后都再确认PAUSE；没有可见暂停时不声称已冻结。暂停中可查看与部署，不需要每选一张卡就恢复。

## 2. 先决定每条路怎么守
1. 找出全部蓝色保护目标，再沿地面通路朝红色入口看回去。分别检查上、中、下路和岔路；观察敌人实际经过的格，不用红蓝之间的直线猜路。
2. 对每条会到蓝点的路径安排拦截。初次不熟悉地图，优先考虑蓝点外侧几格、敌人必经的可部署地面格；有汇合口可优先守汇合口。只有相邻但敌人不会经过的格不能堵路。多个蓝点或未汇合的支路要分别照顾。
3. 从当前卡片选可用地面干员堵口；有多名时优先让能持续挡住来敌的单位守要道，用输出干员补伤害。卡片身份不确定就点选看姓名、费用和面板，别仅凭相似头像命名。
4. 医疗放在后方可部署位置，选朝向时让治疗范围尽量覆盖前排和其他受伤单位；有多条防线时优先找能兼顾的格子。没有医疗卡就使用本局可用的技能/装置应对，不去找不存在的干员。
5. 远程干员选择可部署的高台或其允许的地块，让射程覆盖被前排拦下的敌人和接近蓝点的通路；不要只因为高台靠近蓝点就摆上去。多路尽量兼顾交汇处；飞行敌人用能对空的单位覆盖飞行路线。绿色只表示所选干员允许部署，不全是高台。
6. 恢复前逐条检查“这一路谁拦、谁打、谁治疗”；缺一路不能因为已有两人就结束。先完成当前费用可承担的关键部署，其余按后续费用安排。

## 3. 点卡，拖到格子，选择朝向
1. 保持PAUSE。点底部目标干员卡内部，如“底部右侧费用13、紫色长发头像的卡片”。新图应出现该干员属性和绿色可部署格；卡栏为空先检查是否已全部部署，不点击空白找卡。
2. 使用选卡后的新截图选定一个绿色格；选卡可能改变地图透视和位置，旧坐标不能沿用。向B描述“上/中/下通路＋地面/高台＋唯一地标＋相邻/数格”，例如“左侧蓝色出口右边紧邻的地面格”；示例只是描述方式，具体落点由本局决定。
3. 发一个完整object_drag：从当前底部同一卡片内部重新按住，连续拖到目标格内部再松手。不是点左侧立绘，也不是先点卡再点地面；上次tap已经松手。拖放可斜向、距离要够到格子；方向从卡片指向落点，不能按落点相对装置的方位填写。
4. 松手后取新图：看到角色/白色菱形/方向提示，说明到了选朝向阶段，尚不能当作已经确认部署。此时不点其他卡、不再从卡栏起拖；落点不对时点当前预览的红X取消，再重新选卡放置。
5. 从新图中角色所在格或白菱形中心按住，向计划面向的上、下、左或右方向提示外侧拖动再松手。用physical_gesture，方向不反转；从角色中心出发，不从屏幕正中心或底部卡出发。透视画面按该角色附近的方向提示定位。这里调整的是朝向，不是把已落下的角色再搬到别格。
6. 朝向预览结束后核对费用减少、可放置名额减少、对应卡消失，并在游戏推进后看同格角色和面向。PAUSE时角色可能还处在出现动画，结合这些变化判断是否已登记，不能因身体暂时看不见便重复放人。
7. 给下一位重复选卡→选格→拖放→朝向→核对。医疗和远程用选中/部署预览显示的范围核对覆盖，再确认朝向。

## 4. 部署后继续打，不能在这里报完成
1. 先确认已退出朝向预览，各条要守的路都有安排。倍速显示2X时先点倍速回1X，再点右上三角形恢复；看PAUSE消失、敌人移动或费用增长。
2. 恢复后尽快看下一张图：敌人是否在预计位置被拦下、是否被攻击、干员血量是否下降、其他支路是否漏守。需要重新布置、查看技能或选装置时先再暂停。模型调用期间游戏也在走，不把几秒钟的等待当作安全窗口。
3. 敌人将到蓝点、前排将倒或需连续操作时保持暂停规划；准备好后才恢复，按短段观察。费用不足需等待时，先确认现有防线可撑住再恢复等费用；在PAUSE里wait不会让费用或技能就绪。
4. 已有防线稳定、当前无需操作时，短wait看敌人/结算的变化，不反复点同一人物。新一波从别处来就重新检查该路，不盯住唯一一条路。
5. 看到本次成功/胜利和结算再核对关卡；用户要求停在结算就停。PAUSE、0/12、卡栏为空、布阵完成都不能调用finish成功。失败时按下方恢复流程重试或如实报告，历史三星不是本次胜利。

## 5. 开技能、操作装置和撤退
- 手动技能：暂停→点场上正确干员实体→新图中找该角色旁的技能图标与就绪状态→就绪且需要使用时点技能按钮→看充能消耗或激活标记，并检查是否仍为PAUSE，推进战斗后确认效果。点人物、卡片或左侧技能说明不等于发动；“自动回复、手动触发”仍需要点按钮。
- 未就绪：看当前提示，在防线安全时继续战斗再观察；按钮没亮不要连续点。若显示自动触发/被动，不找不存在的手动发动步骤。要换携带技能，在下一次战前编队/干员页选择，战斗中使用当前带入的技能。
- 医疗/输出范围不对：暂停后点场上该单位，看范围是否覆盖预定格。普通已部署单位不能直接拖到另一格或随便转向；先考虑用其他可用单位补位，再决定是否撤退重放。
- 撤退：先确定撤走不会立刻放过敌人→点场上单位→点该单位面板的撤退按钮→核对角色消失和卡片倒计时。等卡片恢复、费用足够再重新部署；预览红X只是取消待部署，不是撤退按钮。
- 地图装置：按教学指示辨认实物→点装置本体→看展开范围、费用、次数和启动按钮→待敌人在作用范围内、确有需要时点启动控件→看装置状态/敌人变化。只选中不等于启动；没有按钮时先读当前提示，不乱点地图中心。教学提到装置时应把它加入本局操作计划。
- 暂停下技能/装置按钮不可用或效果未推进：不连续强点；先看就绪状态和提示。若确需恢复才可操作，提前确认按钮位置和后续暂停入口，短暂恢复1倍，用新图完成点击、核对效果和暂停状态；不能把“暂停能部署”推广成所有按钮都可立即发动。
- 召唤物/陷阱：从当前出现的额外卡片或技能入口选中→看允许格→按提示放置；未出现朝向提示就不补做朝向手势。确认数量/卡片变化后继续。

## 6. 出错时怎么接着做
先认当前阶段：正在运行且有暂停控件才点暂停，已暂停/选朝向就保留，已结算处理结果。B拒绝、目标不唯一或坐标未执行时，动作没有发生；回看该轮截图补全目标，不记成游戏拒绝部署。再区分没选中、没朝向、朝向被取消或站位无效；完整排查读references/battle-response.md。不因一次失败断言“暂停不能部署”。重试遵守原任务的关卡、次数和资源限制；不切换成消耗理智的模式或自行补充资源。
