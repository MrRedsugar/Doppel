# 操作卡住或局势不对时

先认当前阶段：正在运行且有暂停控件才点暂停，已暂停/选朝向就保留；已到失败或结算页直接处理结果，不继续寻找暂停按钮。记录“在哪一步、什么没发生、下次改哪个具体目标”，不用长篇复述全部经过。

## 输入后没有到下一步
- 点卡后没绿色格：确认点的是底部卡面，检查教学/弹窗/朝向预览是否挡住输入。若已在朝向阶段，继续选朝向，不重选卡；若卡已消失且费用/名额已变化，检查是否已经部署。
- 卡已选中，拖完没朝向：对照新图核对起点在同一卡片内部，终点在绿色格内部；避开装置、墙、格缝。多个相似格就补充所处通路、地标及相邻关系，重新发一次完整拖放，不能只改成“再试一下”。
- 显示方向不一致且动作未执行：核对卡片→落点的连线。目标相对装置在上，不代表相对右下卡也纯向上；可改正确斜向，不能强求竖直或缩短到落点之外。这不是游戏拒绝部署。
- 朝向预览消失，费用和名额不变：核对上一手是否从实际角色/菱形中心起拖，有无落在预览外。若仍有预览直接修正朝向；已取消则重新选卡拖放。不要把预览消失单独当作成功。
- B没找到或说目标不唯一：回看该张图，补充唯一对象描述；缺少对应按钮就先关闭遮挡或处理当前步骤。坐标无效未执行时不记录“已经尝试部署”。
- 同一步多次无变化：检查是否一直沿用同一错误地标、未选卡、落点非法或把人物立绘当拖动起点。换有证据的一个条件再试，不凭空断言“暂停不能部署”。

## 防线出现问题
- 敌人绕过去/逼近蓝点：暂停，沿这只敌人的实际路径找蓝点前尚可部署的地面格，用现有卡补位；其他支路逐条检查，不只在旧站位旁随便加人。来不及补人时看已就绪的输出/控制技能或地图装置。
- 前排被围或将倒：暂停，先查看可用治疗/防御/输出技能；医疗没覆盖就调整后续落点或用其他单位接替。已有敌人被挡住时，不先撤掉唯一堵口者再等冷却。
- 干员一直站着，敌人仍通过：选中看攻击范围，核对敌人是否走在另一条路、是否为飞行目标。把下一名输出放到实际能覆盖的位置；普通单位不能靠反复点敌人来指定攻击。
- 一条路能打、另一条路无人：优先补缺口；若人数不足，找路径真正汇合的位置或利用本局装置，不因为“两个干员都部署了”就恢复长时间等待。
- 没有待部署卡：检查已在场单位、倒计时、技能和装置，继续用现有阵容；空卡栏不等于没有部署过，也不代表任务完成。
- 费用不足/卡冷却：先布置可用的防线，在安全时恢复1倍观察费用/倒计时；有回费技能且已就绪可点。暂停内等待不会攒到所需费用，不自行购买资源。

## 失败、重开和中断
看到MISSION FAILED：记下哪条路漏了或哪位先倒，点“点击画面以继续”；若仍有行动结果页，再按可见继续提示返回。允许重试时，重新进入原关卡→编队→开始行动→处理教学→立即暂停，再针对上次缺口改部署，不能重复同一阵型后称为优化。重试前核对原任务的次数、模式与资源限制，不从演习切换到消耗理智的实战，不自行补充资源；已经耗尽允许次数就如实返回结果。
来电/重连/回到游戏后先确认当前页面和暂停状态；重新开局一定重新暂停。遇到START或可见继续按钮就操作，不因背景在动一直wait。没有新的胜利结算就不报通关。
