# 先守住各条路，再推进战斗

1. 先认阶段：战场正在运行才点可见暂停控件，确认PAUSE；已暂停/选朝向就保留，已结算处理结果。若有教学先按提示推进，关闭对白后重新确认暂停。
2. 从每个蓝色目标向红色入口看通路，给每条未汇合的路线安排可用地面干员；新手布局优先选蓝点附近、敌人确实必经的绿色格。
3. 医疗朝向覆盖前排，远程射程覆盖拦截点和漏守方向。选卡/拖放预览时看实际范围，不只按职业或高台位置猜。
4. 保持暂停逐个完成选卡、拖放、朝向和费用/名额核对；然后恢复1倍观察，敌人快到蓝点或准备新操作就再暂停。
5. 教学提到地图装置时，点选看范围和启动控件，按敌人实际进入范围的画面使用，不只部署角色后等待。
6. 到本次胜利结算才结束；部署完成不是任务完成。

第一次战斗前用read_skill_resource读取name=arknights-deployment、path=references/combat-handbook.md，执行具体手势、技能和装置步骤。已有完整knowledge不重复加载。出错时读该Skill的references/battle-response.md。
