# 打开游戏到大厅

1. 启动明日方舟，等游戏启动画面。看到黄色菱形/播放三角旁有START，就点这个入口；背景介绍仍在轮播也照常点，不一直等介绍结束。
2. 点START后看新图：出现服务器连接进度、罗德岛标志或加载文字，就短wait直到出现大厅菜单。出现可操作的确认/继续按钮则处理，不把所有过渡页都当加载。
3. 出现登录/账号选择时按当前已登录状态继续；确实要求验证码等用户信息才请求协助，不点“清除缓存”来修复普通加载。
4. 大厅可见TERMINAL/终端、编队、干员等入口后进入导航流程。若有公告或奖励弹窗，先点当前可见关闭/确认，再定位大厅“终端”。
5. 等待数次画面仍同一入口时，重新看是否有START/继续/重试，不因为背景在动或只有游戏画布节点就继续空等。网络重连提示则按其可见重试操作，失败保留具体提示。
