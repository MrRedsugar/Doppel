# 设置代理并打到本次结算

## 开始之前
1. 在关卡详情核对代号、名称和理智消耗。1-7应为第一章“暴君”；TR-9“间接防护”在本次验证中是教学关、页面不可用代理，最终以现场代理开关为准；7-1不是1-7。
2. 看“代理指挥”是否可启用。有可用记录才设置代理；按钮不可用时读当前提示，不能仅因以前打过就认定现在能代理，也不自行用额外资源补理智。

## 以1-7两倍代理为例
3. 点“代理指挥”的勾选区，确认已选中。
4. 点旁边循环图标处当前显示的“×N”（例如×1），展开倍率列表；在列表中点×2，观察蓝色选中条移到×2。不要把“代理指挥+”文字末尾的加号当成加一次按钮。
5. 如果列表仍展开，再点当前蓝色选中条里的×2收起。核对详情页当前显示×2、代理已勾选、消耗与倍数一致；已核验1-7普通模式从6变为12。以当前客户端显示为准，不按任务文字假定已经选中。
6. 点蓝色“开始行动”；如果出现编队确认页，再点橙色“开始行动”。出现资源不足/记录失效提示先处理该提示，未实际开始不能记成已刷。
7. 战斗出现后分别核对代理设置仍为×2、详情消耗为12及本次结算计次；右上角1X/2X是战斗速度，与代理×2分开，不能只看到任一处2X就认定另一项正确。
8. 让代理继续到本次结算，核对OPERATION 1-7、行动结束/MISSION RESULTS，以及代理成功次数或本次奖励/消耗提示。已核验旧轮显示“已成功代理作战2次”。用户要求到结算就停，不返回关卡再点开始。

## 其他倍数或中断
- 要其他倍率，在同一列表选用户指定的可见数字，再核对选中值和总消耗；列表没展开先解决入口，不反复点功能名称里的“+”。当前最大值以本机可选项为准。
- 代理报错/失败时先看是否需要接管、重试或退出；没有本次成功结算就报告实际进度，不把代理已开启当成完成。
- TR-9等教学不走代理设置。点详情开始→固定编队→开始→教学/暂停，使用战斗操作手册。
