# 从当前页面找到目标章节和关卡

该文档新版本尚未整体验收；以下具体控件与转场来自 alpha47 已保存实图，入口布局变化时按当前文字/内容确认，不按旧坐标点击。

## 主界面到主线章节
1. 大厅出现TERMINAL/终端后，点这个入口。新页应有当前进度卡、底部分区和“前往上一次作战”；仍是大厅就重新核对终端按钮，不连续盲点。
2. 如果“前往上一次作战”卡片当前恰好写着目标代号和名称，可直接点它进详情；例如当前写TR-9才可作为TR-9快捷入口，写1-7不能当TR-9用。进入后仍核对右侧代号。
3. 否则在终端底部分区找主线/主题曲的书本或竖页图标并点击。预期出现Main Story/主题曲、“曲谱”和故事线封面；底部书本外观是定位线索，进入后用这些页面内容确认，不把图标本身当成功证据。
4. 去1-7或TR-9时选择“为了明日”故事线；当前已选中就继续。这里是章节封面页，“曲谱”“乐章收录”不是音乐播放器；“方舟”是另一故事线，其前面是标志，不是章节数字。

## 章节封面到关卡地图
5. 点右上“乐章收录”，新图应出现按EP编号列出的章节卡。寻找EP01（第一章/黑暗时代下），不点EP15或第十二章。
6. 列表只看到后期EP时，小幅把列表从上往下拖（手指向下、内容向下），让上方较早的章节露出；若已看见EP00/EP01就停。一次只滑一段，看编号变化再决定下一段；与预期相反就重新核对顺序，不一口气来回长滑。
7. 点EP01卡片。若进入“黑暗时代下”的章节介绍页，还要点右下“前往章节”；新图出现带1-x、TR-x节点的地图才算进章。若已直接到地图则跳过这一步。
8. 在地图找目标代号，点带该代号的节点。当前实图中TR-9在1-6之后、1-7之前；目标在当前视野右侧就小幅从右向左拖地图露出它，目标在左侧则反向。每次以可见节点顺序决定，不因首屏没看到就判定未解锁。
9. 右侧详情应显示目标代号和名称：1-7“暴君”，TR-9“间接防护”。若不是目标，关闭详情回到本章地图继续找；锁定时看实际提示，不改打相似编号。

## 详情到战斗
10. 用户只要求“进入/准备，先别开始”，在已核对的详情或准备页停。用户要求代理，按references/stages-and-replay.md设置后开始。
11. 手动战斗点详情蓝色“开始行动”→核对编队→点编队橙色“开始行动”→等待战场→处理教学→立即暂停，接战斗手册。TR-9可能显示固定编队，不尝试修改被锁定的空位。

1-7和7-1不是同一关。目标明确时不自行调换；1-7可用代理需看当前是否已有代理记录，TR-9按手动教学流程。以上未提供固定战斗站位。
