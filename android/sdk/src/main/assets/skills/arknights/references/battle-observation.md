# 看新画面决定下一步

- 有教学对白：读当前提示，点高亮对象或继续；对白关闭后重新确认暂停。
- 战斗正在走：需规划、查看或部署时先点暂停，看到PAUSE再操作。
- 底部卡未选中：点目标卡，看属性和绿色格。
- 已选卡/绿色格出现：从同一卡片内部拖到选定格，松手后看朝向预览。
- 有角色/白菱形：从角色中心向所选方向提示外拖动并松手，不重新点卡。
- 预览关闭、费用/名额减少、卡消失：部署已登记；游戏推进后核对实体和范围，不重复放同一人。
- 卡栏空、仍在战斗：检查已有阵容、敌人和技能/装置；需要时恢复1倍继续，不报完成。
- 敌人进到没守的路、血条危险：暂停，按该Skill的战况排查补防线或开技能。
- 看到本次胜利结算：核对关卡和用户要求；看到失败则处理失败继续/重试，不混用历史三星。

完整操作一次读取：read_skill_resource，name=arknights-deployment，path=references/combat-handbook.md。不要仅凭本摘要执行一条未知的拖放/技能操作。
