# 输入焦点与保存反馈

这是通用方法，具体编辑入口需从当前应用画面确认。

输入之前确认目标。编辑框可见不一定有焦点；单元格高亮通常只能证明选中，不能证明处于文字编辑状态。观察光标、正在编辑的地址/标题、输入区域与键盘反馈。节点明确可编辑时定位该节点；自绘表格若只显示网格，应先寻找当前可见的公式栏、编辑栏或单元格编辑入口，不凭其他 App 的习惯假设双击必然生效。

输入后读回实际文字或编辑区域，并确认提交。输入法“完成”“下一步”与隐藏键盘可能产生不同结果；使用当前宿主支持且目标明确的提交动作，再观察焦点和文本。中文候选仍待选择时不能声称已提交；只看见键盘也不能归因为输入法失败。

切换下一单元格前确认上一格的值已经落在预期地址。键盘遮挡网格会改变可用区域，关闭或出现键盘后重新读取截图/节点，避免沿用旧坐标。在当前编辑状态不明时，不把下一段文本追加到未知字段。

保存前区分文档内容编辑与文件名编辑。根据可见标题、保存图标或当前菜单辨认命名入口；出现文件名或保存位置对话框后核对正在编辑的字段。使用用户指定名称和位置；涉及覆盖同名文件、权限变化或账户登录时，按宿主授权和实际提示处理。

完成证据应尽可能包括保存后的文件名、保存位置/状态和内容。能通过文件读取接口检查时，读回目标文件的实际内容并核对单元格、文本和名称。文件读取能力不可用时明确验证范围；不能把“另存为”对话框已打开、保存按钮已点或标题暂时变化当作文件已经持久保存。
